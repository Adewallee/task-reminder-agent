# 📋 Task Reminder Agent

A simple AI agent built with Node.js and Express that helps users manage tasks via Telex.im using the A2A protocol.

---

## 🚀 Features
- Add tasks using natural language
- List pending tasks
- Responds to A2A-formatted JSON-RPC requests
- Fully compatible with Telex.im workflows

---

## 🛠 Tech Stack
- Node.js
- Express
- UUID
- dotenv

---

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/Adewallee/task-reminder-agent.git
cd task-reminder-agent

# Install dependencies
npm install

# Create .env file
cp .env.example .env
